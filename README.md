# Suryasheel Mourtika - Frontend Developer Portfolio

> Modern, high-performance developer portfolio built with **Angular 17**, **Standalone Components**, **Angular Signals**, and modular **SCSS** design systems.

---

## ✨ Features

- **Angular 17 Standalone Architecture**: Built entirely with standalone components and `ChangeDetectionStrategy.OnPush`.
- **Reactive State with Signals**: `signal()`, `computed()`, and `effect()` for theme toggling and interactive UI state.
- **Glassmorphism Design System**: Modern frosted glass UI with dynamic blur, ambient glow orbs, and light/dark theme contrast.
- **Interactive Hero Canvas**: Real-time design system playground with live SCSS token generation, dynamic blur slider, and 1-click clipboard copy.
- **Floating Glass Pill Navigation**: Floating navbar and footer with unified glass aesthetics and active section dot indicator.
- **Featured Projects Grid**: Responsive showcase of architecture, booking flows, and micro-frontend implementations.
- **Interactive Contact Terminal**: Direct terminal card with live inquiry status, 1-click email copy, and elevated contact form.

---

## 🛠️ Tech Stack

- **Framework**: Angular 17 (Standalone Components)
- **Language**: TypeScript
- **Styling**: SCSS (CSS Custom Properties, Glassmorphism, BEM architecture)
- **Reactivity**: Angular Signals & RxJS
- **Icons**: SVG micro-icons

## 🚀 Getting Started

### Prerequisites

- Node.js (v18.13.0 or higher recommended)
- npm (v9 or higher)
- Angular CLI (`npm install -g @angular/cli`)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Suryasheel24/Portfolio.git
   cd Portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm start
   ```
   Navigate to `http://localhost:4200/` in your browser.

4. Build for production:
   ```bash
   npm run build
   ```
